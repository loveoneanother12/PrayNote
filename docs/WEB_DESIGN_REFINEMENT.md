# PrayNote 웹 디자인 개선 — 2026-09-16

## 방향

Apple Human Interface Guidelines의 정보 위계, 여백, 안전 영역 원칙을 PrayNote의 청색 브랜드와 기존 동선에 적용한다. 네이티브 Liquid Glass를 복제하지 않고 웹에서 가벼운 표면과 읽기 쉬운 콘텐츠를 구현한다.

참고: https://developer.apple.com/design/human-interface-guidelines/layout

## 적용 목록

1. 타이포그래피: 본문 15px, 보조 12–13px, 섹션 19px, 페이지 제목 26–34px. 주요 제목과 선택 항목은 600 두께.
2. 홈: 인사 영역 높이 축소, 단순한 그라데이션, 카드 그림자 완화, 기도 본문 줄간격 확대.
3. 그룹: 헤더 장식 축소, 그룹 카드 높이 압축, 순서 변경과 필터 버튼 확대, 모바일 필터 버튼을 별도 줄로 배치.
4. 내비게이션: 현재 탭 배경과 글자 강조, 스크린리더 현재 페이지 표시, 하단 안전영역 확보.
5. 작성: 공유 대상 안내, 그룹 작성 글자 수, 넉넉한 입력 영역, 16px 입력 글꼴로 모바일 입력 확대 방지.
6. 마이: 프로필·연속 기도·달력의 보조 글씨 확대, 날짜 버튼 최소 높이 확보.
7. 알림: 읽은 항목의 전체 투명도 제거, 읽지 않은 항목은 세미볼드로 구분, 날짜 가독성 개선.
8. 설정: 설정명 15px, 설명 13px로 통일, 항목 사이 호흡과 패널 여백 정돈.
9. 공통: 세그먼트 필터, 44px 주요 조작 영역, 키보드 포커스, 움직임 줄이기, 동적 뷰포트 모달 높이.

## 범위와 배포

웹 및 설치형 PWA 공통 스타일에 적용. 인증, 데이터, 푸시 발송 로직 변경 없음. 사용자 요청에 따라 별도 시각 검수 및 테스트 실행 없이 배포 빌드를 수행한다. 네이티브 Flutter 화면 리디자인은 이번 범위에 포함하지 않는다.
