# PrayNote

비공개 그룹 안에서 기도제목을 나누고 함께 기도했다는 마음을 전하는 웹앱입니다.

## 로컬 실행

1. .env.example을 참고해 .env.local을 만듭니다.
2. npm install을 실행합니다.
3. npm run dev를 실행합니다.

## 현재 구현된 핵심 흐름

- 이메일 매직링크 로그인
- 그룹 개설 및 리더 자동 등록
- 초대코드·초대 링크 가입 신청과 Leader/Admin 승인
- Leader의 Admin 지정, 그룹 정보 수정, 그룹 삭제
- 멤버 목록과 Member/Admin 탈퇴
- 그룹별 기도제목 등록과 한국시간 기준 등록일 저장
- 사용자별 일일 기도 완료 기록 누적
- 내 기도제목의 진행 중/해결됨 분리와 해결일 저장
- 기도제목 상세 보기, 수정, 소프트 삭제
- 그룹별/상태별 기도제목 필터와 실제 내용 검색
- 새 기도·오늘 기도완료·가입 신청/승인·역할 변경 인앱 알림
- 알림 전체/읽지 않음 목록, 개별·전체 읽음 처리와 실시간 화면 갱신
- 표시 이름과 인앱 알림 종류별 설정, 로그아웃
- 모바일 하위 메뉴와 공통 로딩·오류·404 화면

일일 기도 기록은 날짜별 행으로 누적되므로 이후 기도 타임라인, 연속 기도일, 주간·월간 바 차트에 그대로 활용할 수 있습니다.

## 출시 전 검사

`npm run test`, `npm run typecheck`, `npm run lint`, `npm run build`를 순서대로 실행합니다.
